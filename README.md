# 🤝 ONG Mãos Unidas — Plataforma Web Acessível

Bem-vindo ao repositório oficial da plataforma web da **ONG Mãos Unidas**. Este projeto foi desenvolvido com foco em inclusão social, acessibilidade digital, design responsivo e boas práticas de versionamento de software.

---

## 📌 Sobre o Projeto e Funcionalidades

A plataforma tem como objetivo conectar voluntários, doadores e a comunidade aos projetos sociais mantidos pela ONG Mãos Unidas.

### Páginas do Site:
- **Página Inicial (`index.html`):** Apresentação da missão, valores, estatísticas de impacto e chamadas para ação.
- **Projetos Sociais (`html/projetos.html`):** Detalhamento das iniciativas ativas (Alimentação, Educação e Acolhimento).
- **Cadastro de Voluntários (`html/cadastro.html`):** Formulário interativo e acessível para captação de novos voluntários.

---

## 🛠️ Tecnologias Utilizadas e Pré-requisitos

- **HTML5 Semântico:** Estruturação orientada a *landmarks* (`header`, `nav`, `main`, `aside`, `footer`, `article`).
- **CSS3 Responsivo:** Layout adaptável com Grid/Flexbox e suporte a temas.
- **Acessibilidade (WCAG 2.1 Nível AA):** Rótulos WAI-ARIA, suporte total a leitores de tela e navegação por teclado com foco visível.
- **Git & GitHub:** Versionamento com GitFlow e Conventional Commits.

### Pré-requisitos:
Por se tratar de uma aplicação front-end estática, **não há necessidade de instalação de dependências ou gerenciadores de pacotes (como Node/NPM)**. Qualquer navegador moderno (Chrome, Firefox, Edge, Safari) é suficiente para executar a aplicação.
